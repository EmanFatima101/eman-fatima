02 Automation projects

Built in n8n. Running right now.

Every project replaces a task someone used to do by hand. Watch my biggest one run, then see the real workflow.

Lead management and follow-up system

Animated walkthrough of the main stages. Press Execute workflow to run it again.

The real workflow, 19+ nodes in n8n

I previously worked in cold calling and client outreach at a digital marketing agency, and saw how a few hours of delay can cost a conversion. So I built a system that takes a lead from inquiry to proper follow-up.

  • Webhook and validation nodes capture the lead, then a Set node cleans the data
  • Google Sheets logs every lead instantly with a "New" status
  • A business-hours check sends the right auto-reply, and the owner gets an instant alert
  • A Wait node pauses, a Sheets lookup re-checks the status, and a reminder goes out if it is still "New"
  • A final check finds referral leads and thanks the referrer
